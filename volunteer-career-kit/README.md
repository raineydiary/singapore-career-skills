# 狮城职场 · 简历资源与 AI 求职工具礼包

由 **雨雨小天才** 整理，送给狮城职场志愿者，也向所有需要的人开放。核对日期：2026-11-20。

这份礼包把大学官方简历资源和两个新加坡求职 AI Skills 放在同一个入口：先选适合你的模板，再用自己的真实经历写简历，最后准备面试。无需会编程。

**一键领取：** [下载公开礼包 ZIP](Singapore-Career-Kit-Public-20261120.zip?raw=true)，解压后双击 `index.html`。

## 从这里开始

1. **选模板**：打开 [可视化领取页](index.html)，或查看下方资源表。网页打不开时，下载公开 ZIP，解压后双击 `index.html` 即可；大学下载链接需要联网。
2. **下载 Skills**：[简历写作与批改](skills/sg-resume-writing.zip) · [面试准备与模拟](skills/sg-interview-prep.zip)。按你所用 AI 工具的 Skills 导入方式上传 ZIP。也可解压后阅读 `SKILL.md` 与 `references`，将相关内容提供给不支持 Skills 的 AI 使用；这不等同于自动安装。
3. **开始使用**：准备目标岗位 JD、你的经历和选中的模板。先脱敏，再让 AI 改写，最后逐条核实。

### 不知道选哪个？

| 你的情况 | 建议先看 |
|---|---|
| 在新加坡找第一份实习或工作 | NTU 示例 + Harvard Bullet Point / Yale 通用 Word 模板 |
| NUS 在校学生 | NUS 官方 VMock 模板入口；配合 NUS C.A.R. 指南 |
| 商科硕士或已有工作经验 | Yale Experienced Alum、Wharton、Chicago Booth |
| 软件、数据、工程岗位 | Yale Technical、MIT 示例、UPenn 模板 |
| 公益、教育、志愿经历较多 | Yale Common Good Career 模板 |
| 申请 MBA 或商科硕士 | INSEAD、Cambridge、LBS、Oxford；以申请项目要求为准 |

“名校模板”提供结构参考，不代表学校背书，也不能替代岗位要求。旧模板中的地址、照片、国籍、年份、成绩和示例经历都要重新判断；不要保留学校名称或复制别人的成果数字。

## 和两个 Skills 一起用

**改简历：**

> 请使用 sg-resume-writing。我的目标岗位是【岗位】，以下是 JD 和已脱敏的真实经历。请参考我上传的模板，保留我指定的结构，输出英文简历和中文修改说明。不要把 JD 要求写成我已经拥有的经历，不要编造数字；缺失信息先列出来让我确认。

**练面试：**

> 请使用 sg-interview-prep，围绕这份 JD 和最终简历进行模拟面试。一次只问一题。先用 coaching mode 逐题反馈，再用 realistic mode 做整轮模拟；面试结束后给出改进重点。

**把志愿经历写进简历：**

> 以下是我的真实志愿工作记录。请帮我识别其中能支持目标岗位的经历，明确我本人做了什么、和谁协作、有什么可核实的结果。没有量化结果时使用事实性描述，不要替我编造参与人数、增长率或影响规模。

- 可以手动逐份下载。会使用 Python 的读者也可以运行 `python3 download_resources.py`，从校方链接下载已验证文件；程序会核对 SHA-256，变化或失败的文件会单独报告。下载文件不会自动上传到任何地方。
